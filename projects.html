Processing for C++
Full C++ graphics environment built on top of Processing 4, used by students worldwide. Mirrors the Processing Java API (setup, draw, ellipse, loadImage, 3D primitives) directly in C++. Custom parser with real-time error highlighting, OpenGL rendering layer for shaders, textures and fonts, and an export system for Windows and Linux.

Custom Brushless DC Motor (BLDC)
Designed and prototyped a three-phase brushless DC motor from first principles: mechanical design, power electronics, and embedded control in a single closed-loop system. Custom stator/rotor in Fusion 360, Hall effect sensors for rotor position feedback, and drive electronics for three-phase switching and current control.
Embedded C Power electronics Fusion 360 KiCad

Interactive Violin Learning System
Embedded electromechanical feedback system integrated into an acoustic violin for real-time musical instruction. Sensor-driven architecture maps finger position and note input to visual feedback via fiber optic indicators embedded in the instrument. Low-latency signal processing pipeline, ergonomically integrated without degrading acoustic performance.
